# Portfolio d'Ahmed Rofrof

Portfolio personnel realise avec Next.js, React, TypeScript et Tailwind CSS. Il presente mes projets, mon parcours, mes competences et mes coordonnees.

## Demarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans le navigateur.

## Production

```bash
npm run build
npm run start
```

## Images

Les images du portfolio se trouvent dans `public/images`. Les captures des projets sont affichees dans une galerie avec des commandes pour passer d'une image a l'autre.
